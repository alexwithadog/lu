# Personalized desktop assistant project

The comparative research requested on October 14, 2026 is complete as a source/documentation study. Start with [FINDINGS.md](FINDINGS.md).

The central recommendation is an original desktop companion with a quick floating panel, a larger workspace, and an independent task/agent core. For a Windows-first version, evaluate Tauri 2 + TypeScript + Rust, local durable storage, and a supported existing agent runtime. This recommendation is provisional until the user defines their platform, visual identity and top workflows.

Coucou is cloned under `../coucou` at `1456bd3c87f91d6e267516203c84b0148b587120`. It remains an unchanged upstream reference. The user asked to skip MacPy.

The report covers Coucou, CC Switch, Open Dots, Open Interpreter and Tauri, plus Notchi, notch-911, Boring Notch, CatDesk, BongoCat, Pot, Pake, Raycast AI, Jan and Interpreter Workstation's overlay.

Verification boundary: source, documentation, website demos and published screenshots were reviewed. Native assistants were not installed or benchmarked. The original local HTML preview could not be reached through the browser and is not counted as a completed test. No agent hooks, credentials or external app settings were changed.

This report records the initial research stage. Implementation subsequently began as Lu; see the root [README](../README.md), [verification notes](../docs/VERIFICATION.md), and [next priorities](../docs/NEXT.md) for the current application. The earlier pause checkpoint is historical and remains available in `RESEARCH_CHECKPOINT.md`. The optional `../coucou` reference checkout is excluded from Lu's Git repository.
